# 应用更新（0.4.0）

采用 Tauri updater 官方插件和固定的 GitHub Releases latest.json 地址。包下载后由插件校验签名，再启动 Windows 安装器。公开配置仅包含公钥，私钥存储在项目外。

前端共享同一个检查/安装锁，防止自动检查与手动检查并发，安装期间禁用检查和重复安装。默认启动后 3 秒及每 6 小时检查，自动检查开关保存在应用 WebView 本地存储。自动发现更新只显示入口，点击“下载并安装更新”才启动安装。

更新完成说明由 src/release.json 随安装包嵌入；当前版本与本地已读版本不同时显示，用户关闭后才保存已读版本。因此升级中断不会提前消耗新版本的说明。首次安装也显示说明；在设置中可重看。

## 验证范围

- Rust 回归测试：27 项。
- Playwright 界面测试：原有 16 项回归测试和 5 项更新测试通过，覆盖自动发现新版不触发安装、每 6 小时检查及关闭后停止、手动检查无更新、网络失败重试、下载进度与签名失败反馈、偏好持久化、离线说明仅首次弹出及重新查看。
- 独立 Minisign 校验：最终 MSI 和 NSIS 安装包签名有效，翻转文件内容一字节后均被拒绝。
- 真实 WebView2 冒烟测试验证已读版本持久化；发布后使用原生 updater check 校验线上清单。
- 未自动执行安装/卸载或替换当前程序；完整安装重启行为依赖 Tauri 官方安装器，需在实际升级时验证。

发布脚本同时提供 MSI、NSIS 的平台签名及便携程序的 NSIS 回退，更新清单按安装类型选择对应文件。后续发布需保持签名私钥一致。
