# 一键修复验收（0.3.0）

运行概览在 `repair_recommended` 时提供一键修复；确认框显示旧值与目标值。后端从当前用户 AppX 包重新确定目标，前端路径仅作为防止过期确认的前置条件。

写入范围仅为 `HKCU\Environment\CODEX_CLI_PATH`，使用 REG_SZ 保存绝对路径，写入后读回，发送 WM_SETTINGCHANGE，并再次检测健康状态。当前进程不修改自己的环境变量，不终止 Codex。环境通知失败与持久化写入失败分别呈现。

## 验证

- TypeScript / Vite 生产构建通过。
- 27 项 Rust 测试通过，包含未确认拒绝、过期路径拒绝、无效安装拒绝，以及隔离注册表项的缺失值写入、已有值更新、Unicode 路径、其他值保留与只读权限失败。
- 16 项 Playwright / Edge 测试通过，包含修复确认/取消、结构化参数、成功状态刷新、写入失败反馈、无效安装不显示修复入口，以及 680px 窗口确认框。
- 原生冒烟脚本增加未确认与过期目标的拒绝检查，并验证真实 CODEX_CLI_PATH 没有变化。

真实用户环境的写入不作为自动化测试：注册表写入使用独立临时项，测试后清理。真实环境变更广播接收效果、安装/卸载及已有 Codex 重启后行为未在自动化测试中验证。

尚未实现开机检查、更新后自动修复和可回滚的修复历史。
